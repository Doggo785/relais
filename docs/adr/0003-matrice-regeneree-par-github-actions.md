# Matrice des durées régénérée chaque mois par GitHub Actions

Une GitHub Action recalcule la matrice (OSRM) une fois par mois et la publie sur GitHub Pages.
L'appli télécharge la dernière au démarrage et garde la copie livrée avec l'APK en secours. Ainsi
une nouvelle borne TBM est prise en compte sans publier de nouvelle version de l'appli.
